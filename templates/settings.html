Set up automatic sync

Websites can’t read Apple Health directly, so an iPhone app sends it to TimGym. Health Auto Export (App Store) does this on a schedule; its automations need the app’s premium tier.

  1. Generate your TimGym key below{% if has_key %} (or use the one you already set up){% endif %}.
  2. In Health Auto Export, create two Automations of type REST API, both with:
    URL {{ health_url }}
    header Authorization = Bearer YOUR_KEY
    format JSON, export version 2, aggregation Days.
  3. Workouts automation: data type Workouts. Strength workouts are merged with the exercises you log in TimGym that day.
  4. Health metrics automation: Active Energy, Step Count, Weight, Body Fat Percentage, Waist Circumference, Sleep Analysis, and for nutrition Dietary Energy, Protein, Carbohydrates, and Total Fat (written to Apple Health by food apps such as MyFitnessPal, Lose It!, or Cronometer). Each day's body readings become one check-in on your weight chart; a check-in you enter yourself takes precedence.
  5. For the first manual export, pick a short range such as the last 7 days. Very long ranges can exceed the 50 MB upload limit.
  6. Pick a sync interval. The counts above update when TimGym receives data.

If the app only says “error”, run docker compose logs --tail=20 timgym on the server. TimGym logs why it refused each import.

Re-sending the same days is safe: workouts are matched by their Health ID and daily totals are replaced, never doubled.
