Set up automatic sync

Websites can’t read Apple Health directly, so an iPhone app sends it to TimGym. Health Auto Export (App Store) does this on a schedule; its automations need the app’s premium tier.

  1. Generate your TimGym key below{% if has_key %} (or use the one you already set up){% endif %}.
  2. In Health Auto Export, create an Automation of type REST API.
  3. URL: {{ health_url }}
  4. Add a header Authorization with the value Bearer YOUR_KEY.
  5. Format JSON, export version 2, aggregation Days.
  6. Include Workouts, plus the metrics Active Energy and Step Count.
  7. Pick a sync interval, then run it once manually. The counts above update when TimGym receives data.

Re-sending the same days is safe: workouts are matched by their Health ID and daily totals are replaced, never doubled.

Install the app

Workout parser

Notes are read by a parser that runs inside TimGym, with no AI service or extra cost. It understands “Squat 3x5 @ 80”, “Bench 60x8, 70x6, 80x5”, “Deadlift 140 for 5”, “OHP 40kg 8,8,7”, and “3 sets of 8 at 60 lb”. Numbers without a unit are kilograms. Everything stays editable before saving.
